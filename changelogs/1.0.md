# Todium 1.0.0

### General
- Forked from PocketMine-MP 5.44.4 after the project's end of support announcement
- Rebranded to **Todium** across the entire codebase
- Full plugin API compatibility maintained (pocketmine\ namespace preserved)

### Minecraft 1.26.40 Support
- Added support for Minecraft: Bedrock Edition **1.26.40**
- Updated `WorldDataVersions::NETWORK` to **930** (targeting 1.26.40 BDS protocol)
- Updated `WorldDataVersions::LAST_OPENED_IN` to **[1, 26, 40, 0, 0]**
- Updated `WorldDataVersions::BLOCK_STATES` to **1.26.40.0**
- Updated Composer dependencies to target bedrock packages with `+bedrock-1.26.40`:
  - `pocketmine/bedrock-protocol`: `~59.0.0+bedrock-1.26.40`
  - `pocketmine/bedrock-data`: `~6.8.0+bedrock-1.26.40`
  - `pocketmine/bedrock-block-upgrade-schema`: `~5.3.0+bedrock-1.26.40`
  - `pocketmine/bedrock-item-upgrade-schema`: `~1.18.0+bedrock-1.26.40`

### Changes from PocketMine-MP
- Renamed entry point from `src/PocketMine.php` to `src/Todium.php`
- Renamed output phar from `PocketMine-MP.phar` to `Todium.phar`
- Updated all start scripts (`start.sh`, `start.cmd`, `start.ps1`)
- Updated Docker build configuration for Todium
- Updated CI workflows for Todium
- Changed NBT world data version tag from `PMMPDataVersion` to `TodiumDataVersion`
- Updated all author credits and links to Todium Team / todium.dev

### API Changes
- No breaking changes to the plugin API
- The `pocketmine\` namespace is preserved for full plugin compatibility
- `VersionInfo::NAME` now returns `"Todium"` instead of `"PocketMine-MP"`
- `VersionInfo::BASE_VERSION` is now `"1.0.0"` (independent versioning from PMMP)
- `VersionInfo::GITHUB_URL` now points to `https://github.com/todium/Todium`

### Dependencies
- Requires updated `pocketmine/bedrock-protocol` with 1.26.40 packet definitions
- Requires updated `pocketmine/bedrock-data` with 1.26.40 block/item/biome data
- Requires updated block and item upgrade schemas for 1.26.40
- All other pocketmine library dependencies remain unchanged

### Notes
- World data version `WORLD_DATA_VERSION` starts at 1 (independent from PMMP)
- The protocol version number (930) is an estimate and should be verified against the 1.26.40 BDS `protocol_info.json`
- To build from source, use `./install-local-protocol.sh` to link local bedrock package repositories
